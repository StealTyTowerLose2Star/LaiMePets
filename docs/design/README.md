## 版本规则

- **v1.0 / v2.0** — 大版本（产品阶段跨越）
- **v1.1 / v1.2** — 小版本（同阶段内迭代修订）
- 状态标记：`初稿` → `评审中` → `已确认` → `开发中` → `已上线`
