## 0. 安装向导

> 安装向导由 Windows Installer 框架（WiX）承载，但视觉风格保持 LaiMePet 品牌一致。
> 所有安装界面窗口尺寸: **520 × 420px**（固定，不可缩放）。
> 左侧品牌区（180px）使用品牌暖琥珀色渐变背景 + Logo；右侧内容区（340px）白色/暗色背景。

**检测阶段顺序**（首次启动完整检测，共 5 步）：

| 阶段 | 检测内容 | 正常 | 异常处理 |
|------|---------|------|---------|
| 1. 运行环境 | WebView2 版本、系统兼容性 | ✓ 1-2 秒 | 弹窗提示缺少依赖 + 下载链接 |
| 2. Python 引擎 | sidecar 完整性、端口占用 | ✓ 3-15 秒（首次需解压） | 自动修复 / 重新下载 |
| 3. 系统托盘 | 注册托盘图标、注册快捷键 | ✓ <1 秒 | 静默降级（托盘不可用时仍可运行） |
| 4. 性能检测 | GPU 型号、显存、内存 | ✓ 1-3 秒 | 无 GPU → 推荐云端 API + 中性能模式 |
| 5. 宠物数据 | 读取已保存的宠物列表 | ✓ <1 秒 | 无数据 → 进入欢迎页 |

**状态覆盖**：

| 状态 | 表现 |
|------|------|
| **全部通过** | 5 项全部显示绿色 ✓ → 自动过渡到下一界面（欢迎页 / 宠物加载） |
| **首次启动无宠物** | 检测完毕后，Logo 缩小上移 → 窗口展开为欢迎页（§1.1） |
| **已有宠物** | 检测完毕后，Logo 淡出 → 宠物从屏幕边缘走入（§3.1 桌面展示态） |
| **检测失败（可恢复）** | 失败项显示橙色 ⚠ + "重试"按钮；自动重试 1 次 |
| **检测失败（不可恢复）** | 失败项显示红色 ✗ + 错误描述 + "退出"/"查看帮助" 按钮 |

**关键参数**：

| 属性 | 值 |
|------|------|
| 窗口类型 | 透明无边框悬浮窗（`WS_EX_LAYERED` + `WS_EX_TRANSPARENT` 穿透非宠物区域）|
| 宠物尺寸 | 默认高度约 200px（可在设置中调整 0.6x-1.8x）|

| 窗口层级 | `WS_EX_TOPMOST` 置顶，但不抢夺焦点 |
| 多显示器 | 默认跟随主显示器，切换到其他显示器时宠物走入对应屏幕 |

| 追逐尾巴 | 原地转圈追逐尾巴（狗）/ 扑虚拟光点（猫）| 5% |
| 看窗外 | 面朝屏幕外，微抬头 | 4% |


**状态适用场景**：

| 图标状态 | 触发条件 | 优先级(覆盖顺序) |
|----------|---------|-----------------|
| 正常态 | 宠物可见 + 心情开心/正常 | 默认 |
| 暗淡态 | 宠物可见 + 心情难过 | 覆盖正常态 |
| 隐藏态 | 宠物已隐藏 (单击托盘/快捷键) | 覆盖所有常态 |
| 睡眠态 | 宠物 ≥2 小时无互动 → 进入睡觉 | 覆盖正常/暗淡态 |
| 通知态(badge) | 有未读提醒/生成完成/更新 | 叠加在任意状态上 |
| 错误态 | sidecar 崩溃/服务不可用 | 最高优先级，覆盖所有 |

> 多个状态同时触发时，按优先级取最高。通知态 (badge) 为叠加标记，可与除错误态外的任意状态共存。

#### 6.4.4 托盘启动/退出行为

| 行为 | 说明 |
|------|------|
| **开机自启** | 用户可在设置中开启→后续 Windows 启动时自动静默运行。静默启动后：(a)上次关闭时宠物可见→自动显示；(b)上次关闭时已隐藏→仅托盘图标 |
| **关闭到托盘** | 点击固定窗口 × / 托盘菜单→隐藏 → 宠物隐藏 + 托盘图标切换隐藏态。**应用不退出**，后台持续运行（心情计时器、提醒检查） |
| **完全退出** | 托盘菜单→退出 → 确认弹窗 → 关闭 sidecar、清理临时文件、保存状态 → 托盘图标移除、进程退出 |
| **崩溃恢复** | sidecar 意外终止 → 托盘图标变错误态 + 通知气泡提示 → 30s 后自动尝试重启 sidecar（最多 3 次）→ 3 次失败后仅保留托盘图标 + 错误态，WebView 面板仍可打开（仅本地功能如设置可用） |

**状态覆盖**：

| 状态 | 表现 |
|------|------|
| **有 What's New 数据** | 如上，展示功能卡片列表 |
| **无 What's New 数据**（服务器不可达） | 仅显示 "已更新至 v1.1.0" + "开始使用" 按钮，省略功能卡片 |
| **更新日志为空** | "已更新至 v1.1.0" + "本次更新包含稳定性改进和问题修复" + "开始使用" |

**行为规则**：
- What's New 页仅在**更新后首次启动**时显示，普通启动不展示
- 用户点击"开始使用"或关闭面板 → 进入正常初始化流程（§1.0）
- 面板关闭后不再自动弹出（记录已读版本号到本地存储）

## 9. 响应式与屏幕适配

> V1.0 Windows 桌面端为主，以下为已覆盖的适配维度：

| 适配维度 | 策略 |
|---------|------|
| **屏幕分辨率** | 宠物初始位置基于屏幕右下角百分比定位（非绝对像素）|
| **多显示器** | 宠物跟随当前活跃显示器；切换时走入新屏幕 |
| **高 DPI** | 宠物模型和 UI 面板按系统缩放比例渲染，4K 屏下保持清晰 |
| **全屏应用** | 检测全屏窗口 → 宠物自动隐藏，退出全屏后恢复 |
| **锁屏/睡眠** | 宠物进入睡觉态，唤醒后伸懒腰 |
| **纵向屏幕** | 宠物调整定位到底部中间 |
