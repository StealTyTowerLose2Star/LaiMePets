## 0. 全局布局规范

### 0.1 窗口层级

```
┌─ Z-Index 层级 ──────────────────────────────────┐
│                                                   │
│  z-0    桌面层 — 宠物本体（透明无边框悬浮窗）        │
│  z-10   宠物附属 — 心情指示器（始终跟随宠物）        │
│  z-20   悬停层 — 悬停控制条（hover 触发）           │
│  z-30   菜单层 — 右键菜单、子菜单                   │
│  z-40   通知层 — Toast 通知堆叠                    │
│  z-50   面板层 — 主控制面板（Mica）                 │
│  z-60   弹窗/遮罩层 — 确认对话框 + 遮罩              │
│  z-100  加载层 — 全屏加载（生成形象时）              │
│                                                   │
└───────────────────────────────────────────────────┘
```

## 3. 桌面展示态

### 3.1 悬浮窗模式（默认）

这是用户 80% 时间看到的界面 — **宠物直接在桌面上，无窗口边框**。

```
┌──────────────── 用户桌面 ─────────────────┐
│                                           │
│         [Chrome 浏览器窗口]                 │
│                                           │
│    ┌──────────────┐                       │
│    │ 文件资源管理器  │                       │
│    └──────────────┘                       │
│                                    ●      │  ← 迷你心情指示器
│                                  🐱       │  ← 宠物（3D 渲染）
│                             [桌宠活动区域]  │     完全透明背景
│                                           │     点击穿透非宠物区域
│  ┌─────────────────────┐                  │
│  │     VS Code         │                  │
│  │                     │                  │
│  └─────────────────────┘                  │
│                                           │
│                       🖥️ 任务栏            │
│                    [🐱 LaiMePet 托盘]      │
└───────────────────────────────────────────┘
```

**关键参数**：

| 属性 | 值 |
|------|------|
| 窗口类型 | 透明无边框悬浮窗（`WS_EX_LAYERED` + `WS_EX_TRANSPARENT` 穿透非宠物区域）|
| 宠物尺寸 | 默认高度约 200px（可在设置中调整 0.6x-1.8x）|
| 初始位置 | 桌面右下角，距离底部任务栏 60px，距离右侧 40px |
| 活动范围 | 桌面右下 1/4 区域为主（避免遮挡核心工作区）|

| 窗口层级 | `WS_EX_TOPMOST` 置顶，但不抢夺焦点 |

| 趴下休息 | 宠物趴下，前爪前伸，头放爪上 | 20% |
| 伸懒腰 | 前爪前伸压低上身，后腿蹬直 | 8% |
| 舔毛 | 转头舔舐身体侧面毛 | 8% |
| 追逐尾巴 | 原地转圈追逐尾巴（狗）/ 扑虚拟光点（猫）| 5% |
| 看窗外 | 面朝屏幕外，微抬头 | 4% |

## 8. 响应式与屏幕适配

> V1.0 Windows 桌面端为主，以下为已覆盖的适配维度：

| 适配维度 | 策略 |
|---------|------|
| **屏幕分辨率** | 宠物初始位置基于屏幕右下角百分比定位（非绝对像素）|
| **多显示器** | 宠物跟随当前活跃显示器；切换时走入新屏幕 |
| **高 DPI** | 宠物模型和 UI 面板按系统缩放比例渲染，4K 屏下保持清晰 |
| **全屏应用** | 检测全屏窗口 → 宠物自动隐藏，退出全屏后恢复 |
| **锁屏/睡眠** | 宠物进入睡觉态，唤醒后伸懒腰 |
| **纵向屏幕** | 宠物调整定位到底部中间 |
